# FunPay Bot

Telegram-панель для FunPay под одну конкретную витрину: верификация номера Claude.ai на аккаунте клиента. Интеграция с Hero SMS для приёма кодов подтверждения.

## Что настроено

- Папка проекта: `C:\Users\рррр\Desktop\FunPayBot`
- 10 товаров только под подтверждение номера/SMS для Claude.ai.
- Цены товаров: 80, 90, 100, 110, 120, 130, 150, 170, 190 и 200 руб.
- В описаниях прямо указано: аккаунты, почты и подписки не продаются.
- Категория FunPay: `3172` — `https://funpay.com/lots/3172/`.
- Hero SMS API: покупка виртуальных номеров и приём SMS-кодов.
- Telegram-бот с меню: статус, каталог, превью текста, проверка FunPay, ручное поднятие, авто-поднятие, Hero SMS.

## Быстрый запуск

1. Открой `config.json`.
2. Заполни:
   - `telegram.token` - токен Telegram-бота от BotFather.
   - `telegram.password` - пароль для входа в панель.
   - `funpay.golden_key` - cookie `golden_key` от авторизованного FunPay.
   - `funpay.category_ids` - ID категории для поднятия предложений, сейчас стоит `3172`.
   - `hero_sms.api_key` - API-ключ от личного кабинета hero-sms.com.
3. Запусти `start.bat`.
4. Напиши `/start` боту в Telegram и введи пароль.

## Hero SMS — приём кодов подтверждения

Бот подключен к Hero SMS API для покупки виртуальных номеров и автоматического приёма SMS-кодов.

### Как пользоваться через Telegram

1. Нажми `Hero SMS` в главном меню.
2. `Баланс` — проверить баланс Hero SMS.
3. `Получить номер` — купить виртуальный номер (сервис и страна из конфига, по умолчанию `cl` / Россия).
4. `Проверить код` — проверить, пришёл ли SMS-код на активный номер.
5. `Ждать код` — бот сам поллит статус и пришлёт код, когда тот придёт.
6. `Завершить` — завершить активацию (код принят).
7. `Отменить` — отменить активацию (вернёт часть денег).
8. `Активные` — список всех активных активаций на аккаунте Hero SMS.

### Команды

- `/hero_balance` — баланс.
- `/hero_number` — получить номер.
- `/hero_code` — проверить код.
- `/hero_wait` — ждать код с поллингом.
- `/hero_finish` — завершить.
- `/hero_cancel` — отменить.
- `/hero_active` — активные активации.

### Настройки Hero SMS в config.json

- `hero_sms.api_key` — API-ключ (обязательно).
- `hero_sms.default_service` — код сервиса по умолчанию. `cl` = Claude.ai.
- `hero_sms.default_country` — ID страны по умолчанию. `0` = Россия, `16` = UK, `43` = Германия.
- `hero_sms.max_price` — максимальная цена номера (0 = без лимита).
- `hero_sms.poll_interval` — интервал проверки кода в секундах (по умолчанию 5).
- `hero_sms.wait_timeout` — таймаут ожидания кода в секундах (по умолчанию 300).
- `hero_sms.proxy` — прокси для Hero SMS.

## Как выставить товары

Автоматическое создание лотов на FunPay не используется: бот готовит тексты, а ты вручную создаешь предложения в нужной категории.

1. В Telegram нажми `Превью текста` или открой `data/funpay_listing_preview.md` после запуска.
2. Создай 10 предложений на FunPay с ценами из витрины.
3. Вставь текст нужного товара из `/preview` в описание предложения.
4. После создания предложений используй `/bump_now` или авто-поднятие.

## Где менять товары и цены

Все товары лежат в `config.json` -> `service.tiers`.

Можно менять:

- `title` - заголовок предложения.
- `price` / `old_price` - текущая и старая цена.
- `quality` - короткое позиционирование.
- `badge` - метка товара.
- `warranty` - гарантия только в пределах реальной услуги.
- `description` - описание для покупателя.
- `delivery_format` - формат оказания услуги.

## Команды Telegram

- `/start` - вход и меню.
- `/status` - состояние бота.
- `/settings` - указать токены, cookies, категории и интервал.
- `/catalog` - короткий список товаров.
- `/preview` - готовые тексты для FunPay.
- `/publish_plan` - список товаров, цен и ссылок создания предложений FunPay.
- `/bump_now` - ручное поднятие с подтверждением.
- `/autobump_on` / `/autobump_off` - включить/выключить авто-поднятие в текущем запуске.
- `/hero_balance` - баланс Hero SMS.
- `/hero_number` - получить виртуальный номер.
- `/hero_code` - проверить SMS-код.
- `/hero_wait` - ждать SMS-код с поллингом.
- `/hero_finish` - завершить активацию.
- `/hero_cancel` - отменить активацию.
- `/hero_active` - список активных активаций.

## Настройка через Telegram

После первого запуска открой `/settings`. Там можно указать:

- FunPay `golden_key`
- FunPay `User-Agent`
- FunPay proxy
- ID категорий FunPay
- Telegram token
- пароль Telegram-бота
- admin IDs
- интервал автоподнятия
- Hero SMS `api_key`
- Hero SMS сервис (код, например `cl`)
- Hero SMS страна (ID, например `0` = Россия)
- Hero SMS proxy

Telegram token для самого первого запуска всё равно должен быть указан заранее в `config.json` или `.env`, иначе Telegram-бот не сможет стартовать. Если поменять Telegram token через `/settings`, перезапусти процесс.
