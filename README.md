# FunPay Bot

Отдельный бот под FunPay: Telegram-панель, маркетинговые тарифы для услуги Claude.ai и автоподнятие категорий 24/7.

## Что уже настроено

- Отдельная папка: `C:\Users\рррр\Desktop\FunPayBot`
- Три тарифа для FunPay: START / ЛЮКС / PREMIUM с разной ценой и подачей.
- Категория FunPay для Claude: `3172` — `https://funpay.com/lots/3172/`.
- Расширенная витрина под FunPay: дешевые готовые аккаунты, региональные аккаунты, регистрация на почту, SMS-активация, Claude Code, Multi AI, Pro/Max.
- Telegram-бот с меню: статус, каталог, превью текста, проверка сессии, ручное поднятие, авто-поднятие on/off.
- Авто-поднятие по `category_ids` с интервалом, джиттером и опциональными тихими часами.
- Безопасный режим `dry_run: true` по умолчанию: бот ничего реально не поднимает и не пишет на FunPay, пока ты сам не включишь.

## Быстрый запуск

1. Открой `config.json`.
2. Заполни:
   - `telegram.token` - токен Telegram-бота от BotFather.
   - `telegram.password` - пароль для входа в панель.
   - `funpay.golden_key` - cookie `golden_key` от авторизованного FunPay.
   - `funpay.category_ids` - ID категорий, где нужно поднимать предложения.
3. Запусти `start.bat`.
4. Напиши `/start` боту в Telegram и введи пароль.

## Важный режим безопасности

По умолчанию стоит:

```json
"dry_run": true,
"marketplace_writes_enabled": false
```

Так бот только показывает, что сделал бы. Для реального поднятия нужно осознанно поменять:

```json
"dry_run": false,
"marketplace_writes_enabled": true
```

После этого перезапусти `start.bat`.

## Как выставить услугу

Автоматическое создание/редактирование лотов на FunPay нестабильно и зависит от формы конкретной категории. Поэтому бот генерирует готовые тексты для лотов и поднимает уже созданные предложения.

1. В Telegram нажми `Превью текста` или открой `data/funpay_listing_preview.md` после запуска.
2. Создай 3 предложения на FunPay в нужной категории:
   - START - 379 руб.
   - ЛЮКС - 499 руб.
   - PREMIUM - 699 руб.
3. Добавь ID категории в `funpay.category_ids`.
4. Включи реальный режим и автоподнятие.

## Где менять маркетинг и цены

Все тарифы лежат в `config.json` -> `service.tiers`.

Можно менять:

- `title` - заголовок предложения.
- `price` / `old_price` - текущая и старая цена.
- `quality` - качество/позиционирование.
- `warranty` - гарантия, только если реально готов ее выполнять.
- `description` - продающее описание.

## Команды Telegram

- `/start` - вход и меню.
- `/status` - состояние бота.
- `/settings` - указать токены, ключи, cookies, категории и режим работы прямо в Telegram.
- `/catalog` - тарифы.
- `/preview` - текст для FunPay.
- `/publish_plan` - список товаров, цен и ссылок создания предложений FunPay.
- `/bump_now` - ручное поднятие с подтверждением.
- `/autobump_on` / `/autobump_off` - включить/выключить авто-поднятие в текущем запуске.

## Настройка через Telegram

После первого запуска открой `/settings`. Там можно указать:

- FunPay `golden_key`
- FunPay `User-Agent`
- FunPay proxy
- ID категорий FunPay
- Telegram token
- пароль Telegram-бота
- admin IDs
- интервал автоподнятия
- `dry_run` и разрешение реальных действий

Telegram token для самого первого запуска всё равно должен быть указан заранее в `config.json` или `.env`, иначе Telegram-бот не сможет стартовать. Если поменять Telegram token через `/settings`, перезапусти процесс на BotHost.
